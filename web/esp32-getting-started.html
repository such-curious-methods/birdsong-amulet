Getting started with ESP32

Build your own projects, without C++ or the terminal.

Your board

The Amulet is built on a DFRobot FireBeetle 2 ESP32-E: an ESP32 with Wi-Fi, Bluetooth, a USB-C port, a battery charger and an RGB LED. Its firmware is written in C with Espressif's ESP-IDF, but you do not need either to start your own projects.

Trying these replaces the Amulet firmware. To turn your board back into an Amulet, use Install or update firmware and choose Fresh install.

Gentle ways in

MicroPython in Thonny

Thonny is a beginner-friendly Python editor that can install MicroPython on the board for you. You write Python, press Run, and see the results right away. Bluetooth scanning is built in; try the scanning script.

MicroBlocks

MicroBlocks is drag-and-drop blocks, like Scratch, for real hardware. It runs in Chrome or Edge with nothing to install.

Wokwi

Wokwi simulates an ESP32 in your browser, with virtual LEDs, buttons and sensors, so you can start before you have a board.

Arduino IDE

Still C++, but with buttons instead of a terminal and examples for almost everything. Link to be added.
