Amulet workshop instrument

Problems and fixes.

Most install problems come down to the browser, the cable or a driver. Find what you're seeing below. If nothing helps, ask a workshop helper.

Browser

Before anything else

The page says this browser can't install firmware

Why
Installing uses Web Serial, a browser feature for talking to USB devices. Chrome and Edge on computers have it. Safari and every browser on iPhone and iPad don't.
Fix
Open this page in Chrome or Edge on a Mac, Windows or Linux computer, or a Chromebook. Recent Firefox versions have added Web Serial, but this installer hasn't been tested there.

The page says it needs a secure page

Why
Browsers only allow USB access from https:// pages (or from localhost on your own computer).
Fix
Open the page from its https:// address, not a saved copy or a plain http:// link.

Finding the Amulet

No port, or the wrong port

The port list is empty, or the Amulet never shows up

Why
The most common cause by far is a charge-only USB cable: it powers the Amulet but carries no data. The next most common is a missing or broken driver for the Amulet's USB chip (a CH340).
Fix
Try a different cable that you know syncs data, and a different USB port. If it still doesn't appear, check the driver section for your computer below.

Several identical entries appear in the list

Why
The Amulet's USB chip has no serial number, so several Amulets look the same to the browser.
Fix
Plug in one Amulet at a time.

"Failed to open serial port" or the port is busy

Why
Only one program can use the Amulet at a time. The Tone Atelier in another tab, a serial monitor, or tools like the Arduino IDE may be holding it.
Fix
Press Disconnect in the Tone Atelier, close other tabs or programs that might use the port, then try again. Unplugging and replugging the Amulet also releases it.

Drivers

Your computer and the CH340 chip

Windows

Why
Windows normally installs the CH340 driver automatically through Windows Update. Some automatic updates have installed a version that doesn't work.
Fix
Wait a minute after plugging in the first time while Windows finds the driver. If the port appears but installing fails, ask a helper for the CH340 driver installer from the chip maker, WCH, or roll the driver back in Device Manager.

macOS

Why
Recent versions of macOS include a CH340 driver. An older driver installed by hand for other projects can conflict with it and create duplicate or dead ports.
Fix
If you see two similar ports, try each. If neither works and you once installed a CH340 or CH341 driver yourself, removing it usually helps. Ask a helper.

Linux

Why
The driver is built in, but your user needs permission to use serial ports. On Ubuntu and Linux Mint, a braille-display service called BRLTTY can also grab the Amulet and make it vanish a moment after you plug it in.
Fix
Add yourself to the serial group with sudo usermod -aG dialout $USER, then log out and back in. On Ubuntu or Mint, if you don't use a braille display, remove BRLTTY with sudo apt remove brltty.

Installing

During and after the install

The installer asks whether to erase the device

Why
Erasing wipes everything on the Amulet, including the melodies and colors you saved.
Fix
For a normal update, leave Erase unchecked. Use "Erase and install" only for a new board or when an update didn't fix a problem.

"Failed to connect" or the install never starts

Why
The installer restarts the Amulet into a special loading mode through the USB chip. Occasionally the timing misses on some computers.
Fix
Unplug the Amulet, plug it back in and try again. If it keeps failing, ask a helper, who can put the board into loading mode by hand.

It seems slow, or it stopped partway

Why
Installing takes about a minute. If the cable is bumped or the computer sleeps, it stops partway.
Fix
Keep the Amulet plugged in and the computer awake until it finishes. If it stopped partway, just run the install again; the Amulet recovers.

My melodies are gone after installing

Why
The board was erased: "Erase and install" was used, or the Erase box was checked during an update.
Fix
Compose them again in the Tone Atelier and press Save. Next time, use "Update my Amulet" and leave Erase unchecked.

The Tone Atelier says the firmware is too old

Why
Newer features, such as rests in a melody, need the current firmware.
Fix
Disconnect in the Tone Atelier, then come back here and use "Update my Amulet".
